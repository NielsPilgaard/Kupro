# Task 006: MCP server

See [ADR-001](../docs/adr/ADR-001-agent-parity.md), [ADR-005](../docs/adr/ADR-005-auth-keycloak.md).

## Scope

- Official C# MCP SDK; tools call feature services directly.
- Coarse tool set (~12): `search_issues`, `get_issue`, `create_issues`, `update_issues`, `add_comment`, `list_projects`, `list_sprints`, `get_plan`, ...
- OAuth via Keycloak: DCR + experimental `resource-indicators,cimd` features ([ADR-005](../docs/adr/ADR-005-auth-keycloak.md) IMP-001); fallback pre-registered client.
- Serve Protected Resource Metadata (`/.well-known/oauth-protected-resource`) from the API.
- `flowstate mcp` stdio bridge using the CLI's token.
- Parity test: OpenAPI operations <-> CLI commands <-> MCP tools.

## Acceptance criteria

- [ ] Claude Code connects via remote URL and via `flowstate mcp`, and can manage issues.
- [ ] Parity test fails when a new endpoint has no CLI/MCP surface.
