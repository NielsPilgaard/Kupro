# The name Kupro

## TL;DR

- **Kupro** (say "KOO-pro"): Latin *cuprum*, copper, spelled with a Nordic K. Copper is what the whole identity is
  built on ([branding.md](branding.md#name-and-wordmark)).
- Chosen in October 2026. It replaces the working name Flowstate, which another developer platform already uses.
- Forms and spelling rules for the name: [branding.md](branding.md#name-and-wordmark).

## What we looked for

- Short, catchy and easy for English speakers to read and say; it also has to work in Danish.
- Not already the name of a software product.
- A name we could own across domains and social handles.
- A hint of the promise: plan ahead. The early one-liner was "Get ahead of yourself" (Danish: "Få et forspring").

Plain English words and well-known myth names were nearly all in use already. Invented words and old Latin or Norse
roots were where the open names were.

## Alternatives considered

| Name | Idea | Why not |
|---|---|---|
| Cupro | Latin root of copper | Also a well-known fabric; easily confused with an existing CRM |
| Aetlan | Old Norse *ætlan*: "thought; design, plan" (English kept the root as *ettle*, to intend) | Hard for English speakers to say |
| Etlan | Aetlan with easier spelling | Reads like "ETL"; close to an existing data catalog |
| Aetlun, Aetlo | Variants of Aetlan (Icelandic *áætlun* = plan, schedule) | Same pronunciation problem |
| Foresprint | fore + sprint; sounds like Danish *forspring* (head start) | Shortlisted; Kupro chosen |
| Cupri, Eirr | Latin "of copper"; Old Norse *eir*, copper | Shortlisted; Kupro chosen |
| Snemma, Forsja | Old Norse "early"; *forsjá*, foresight | Shortlisted; Kupro chosen |
| Antevorta | Roman goddess of the future | Shortlisted; long |
| Danish compounds (Holdkurs, Nordspor, Fremtakt, …) | Plain Danish | The name has to work in English first |
| Steadyship, Paceline, Underway, Forereach | Sailing and pacing words | Not catchy enough |
| Planr, Planly, and plain or myth words (cadence, headway, Frigg, Mimir, …) | Obvious planning words | Already used by other software products |
