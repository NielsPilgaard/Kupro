# Security policy

## Reporting a vulnerability

Please don't open a public issue. Report it privately through GitHub:
[**Report a vulnerability**](https://github.com/NielsPilgaard/Kupro/security/advisories/new).

Include what you found, how to reproduce it, and the impact you expect. You'll get an answer within 5 working days.
Once it is fixed, the advisory is published with credit to you, unless you'd rather stay anonymous.

## Supported versions

Kupro has no releases yet. Fixes go to `main` only.

## Scope

In scope: the API, web app, CLI, MCP server, the Keycloak realm and theme in this repo, and the generated deploy
configuration. Out of scope: findings that need a compromised server or admin account, missing hardening headers
without a working attack, and denial of service by volume.
